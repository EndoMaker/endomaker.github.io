ESP32 Bluetooth game device

Developed an ESP32 Bluetooth game device, combining power-circuit design, C++ firmware, BLE, and a TFT display.

Area
Embedded
Timeline
May – Jun 2026
Status
Developed
BLE+ TFT graphics

Project details

  • Rechargeable LiPo circuit with transistor-switched display power to reduce idle consumption.
  • C++ firmware with custom flash partitions to run BLE and TFT graphics concurrently.
  • Reverse-engineered BLE pairing authentication to connect the device to a closed-source mobile app.
