# Jonathan de Souza — Mechanical Engineering Portfolio

A static portfolio featuring mechanical design, robotics, fabrication, and embedded systems projects.

## Local preview

Open `index.html` in a browser, or run `python -m http.server 8765` in this folder and visit `http://127.0.0.1:8765/`.

The project graphics are typographic treatments of technical specifications. Original project photos and CAD renders can be added later.

The site uses self-hosted IBM Plex fonts under the SIL Open Font License; see `assets/fonts/LICENSE.txt`. There are no external runtime dependencies.
